# Recipe Share

Recipe Share is a PHP and MySQL web application created for my Software and Web Development capstone project. The site allows users to browse, submit, rate, and print homemade recipes. It also includes login-based features and admin tools for reviewing and managing submitted content.

## Main Features

- User registration and login
- Personalized navigation for logged-in users
- Recipe submission with dynamic ingredients and steps
- Server-side validation and sticky form fields
- Image uploads for recipes
- Recipe search, filtering, and sorting
- Category chips for type, style, and diet
- Recipe rating system with average star ratings
- Top-rated recipe highlighting
- Optional YouTube video embeds
- Print-friendly recipe view
- Admin approval system for pending recipes
- Admin tools for approving, rejecting, deleting, and managing categories

## Technologies Used

- PHP
- MySQL / MariaDB
- HTML
- CSS
- JavaScript
- Apache / XAMPP / MAMP
- phpMyAdmin

## Database

The database is named `recipe_share`.

A database dump is included with the submission at `assets/michael-leonardo-db-dump.sql`.

This file can be imported through phpMyAdmin or another MySQL/MariaDB tool to recreate the database structure and sample data.

## Setup Notes

1. Place the project folder in a local server directory such as `htdocs`.
2. Start Apache and MySQL.
3. Import `assets/michael-leonardo-db-dump.sql`.
4. Update database connection settings if needed.
5. Open the project through a local server URL, such as `http://localhost/recipe-share/`.
